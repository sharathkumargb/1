LEARNCODEWITHSHARU WEBSITE

FILES
- index.html: website structure
- style.css: website design
- script.js: 20 Java programs, navigation, copy button and memory game

OPEN IN VS CODE
1. Extract this folder.
2. VS Code > File > Open Folder > select learncodewithsharu.
3. Open index.html.
4. Use Live Server, or open index.html in your browser.

ADD YOUR RESUME
1. Save your actual resume as resume.pdf.
2. Put resume.pdf in the same folder as index.html, style.css and script.js.
3. Test the Download Resume button.

PUBLISH WITH GITHUB PAGES
1. Create a NEW public repository named learncodewithsharu.
2. Upload index.html, style.css and script.js directly into the repository root.
3. Upload resume.pdf too, if you want the resume link to work online.
4. Commit changes.
5. Settings > Pages > Deploy from a branch.
6. Choose main and /(root), then Save.
7. Wait for GitHub Pages to publish. The URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/learncodewithsharu/

NOTE
The site is static and does not need Java installed on the visitor's computer to read the displayed Java examples. The memory game runs in the browser. External Google Fonts need an internet connection; system fonts will be used if unavailable.
